POLYTECHNIC COURSE REGISTRATION SYSTEM (PCRS)
Simple PHP + MySQL version

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy this PCRS folder into:
   C:\xampp\htdocs\

4. Open phpMyAdmin:
   http://localhost/phpmyadmin

5. Create/import database.sql.

6. Open:
   http://localhost/PCRS_Simple/
